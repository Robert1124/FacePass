Read the docs View on GitHub

Not Apple Face ID, Touch ID, system biometrics, or a replacement for macOS authentication.

What FacePass does

Focused assistance, not broad autofill.

FacePass is a native macOS 13+ menu-bar app. It keeps recognition, conditions, password retrieval, and Accessibility actions local to the Mac.

It supports the macOS lock screen and approved administrator/System Settings authorization prompts only. Ordinary webpage or app password fields are not supported targets.

Safety boundaries

Built around explicit limits.

Lock-screen only Return

The lock-screen assist path may type the Keychain password and press Return only after locked-session checks and local recognition pass.

Prompt fill is value-only

Administrator/System Settings prompt handling fills the password value only. It never clicks OK, Continue, Modify Settings, Login, submit, or presses Return.

No broad password targeting

FacePass rejects ordinary website and app password fields. Detection is narrow, allowlisted, and aimed at approved macOS authorization contexts.

How it works

Short windows. Local checks. Clear exits.

Confirm scope

FacePass first confirms the requested flow is one of the approved macOS targets.

Run local recognition

Camera use is short-lived and local. Raw frames and photos are not persisted.

Apply the narrow action

FacePass fills or types only within the approved behavior for that specific flow.

Feature highlights

Small surface area, practical controls.

Menu-bar app

A lightweight background app with a full settings window.

Keychain storage

Password material is stored only through macOS Keychain.

Automation conditions

Automatic actions can require Wi-Fi, external display, or power-state conditions.

Prompt allowlist

Authorization prompt detection stays narrow and context-based.

Privacy

No cloud service. No analytics. No telemetry.

  • No password values in files, logs, screenshots, or debug output.
  • No upload of face data, passwords, unlock state, Wi-Fi details, display identifiers, or environment signals.
  • Recognition templates are local encrypted data, not raw face photos or video frames.
